# Formato fantasie — Sportswear 3D

## File consigliato

Per le fantasie della divisa usa **PNG quadrato 1024×1024 px**, preferibilmente **seamless/tileable** (il bordo destro continua nel sinistro e il bordo alto continua nel basso).

Supportati dal configuratore:
- PNG — consigliato, anche con trasparenza;
- JPG/JPEG;
- WebP.

Limite: **8 MB per file**.

## Come preparare una fantasia

1. Crea una tavola quadrata 1024×1024 px.
2. Disegna il motivo che deve ripetersi sul tessuto.
3. Se vuoi che il colore base scelto nel configuratore rimanga visibile, usa un PNG con aree trasparenti.
4. Se vuoi una grafica completamente a colori, usa un PNG/JPG/WebP opaco.
5. Per evitare giunte visibili, prepara il motivo come tile seamless.

Nel configuratore puoi poi regolare:
- ripetizione;
- rotazione;
- offset X/Y;
- opacità.

Ogni parte può avere una fantasia diversa:
- corpo maglia;
- maniche;
- colletto;
- pantaloncini;
- calze.

## Loghi, sponsor e patch

Formato consigliato: **PNG con sfondo trasparente**, 512–2048 px sul lato lungo.

Sono supportati anche JPG e WebP, fino a 8 MB.

Ogni elemento grafico può avere:
- superficie indipendente;
- posizione X/Y;
- scala;
- rotazione;
- opacità.

Superfici disponibili:
- maglia fronte;
- maglia retro;
- manica sinistra;
- manica destra;
- pantaloncino sinistro;
- pantaloncino destro;
- calza sinistra;
- calza destra.

## Font personalizzati

Per nome e numero/caratteri puoi caricare in memoria browser:
- TTF;
- OTF;
- WOFF;
- WOFF2.

Limite: **5 MB**.

Il font non viene salvato sul server né inserito nel payload; il payload registra soltanto che è presente un font personalizzato e deve essere ricaricato per ricostruire la configurazione.
